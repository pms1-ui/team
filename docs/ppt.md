# Childy 투자제안서 스타일 제작 가이드

이 문서는 사용자가 PPT, PDF, 발표자료, 제안서, 투자제안서, 회사소개서, 프리젠테이션 웹페이지 제작을 요청할 때 기본으로 적용할 Childy 회사 양식 가이드다.  
작성자는 Childy DX팀 팀장 관점에서, 투자자/파트너/내부 의사결정자를 설득하는 정돈된 비즈니스 자료를 만드는 것을 목표로 한다.

## 기준 자료

- 기준 PDF: `Attatched file/투자제안서.pdf`
- 원본 성격: 35페이지, 16:9 와이드 슬라이드형 PDF
- 페이지 크기: 1920 x 1080 pt
- 핵심 인상: 흰 캔버스, 브랜드 블루 포인트, 굵은 제목, 표/차트/이미지 중심의 근거 제시, 절제된 IR/투자제안서 톤

PDF의 구체적인 투자 내용이나 민감한 문장은 사용자가 명시적으로 요청하지 않는 한 재사용하지 않는다. 이 문서는 시각 양식과 제작 규칙을 재사용하기 위한 것이다.

## 기본 제작 원칙

1. 모든 발표자료는 기본 16:9 와이드 비율로 만든다.
2. 커버 슬라이드는 풀 블루 배경을 사용한다.
3. 본문 슬라이드는 대부분 흰 배경을 유지한다.
4. 본문 슬라이드의 좌상단에는 파란 세로 바를 둔다.
5. 슬라이드 상단 좌측에는 작은 파란 섹션 라벨을 둔다.
6. 제목은 좌측에 크게 배치하고, 근거 자료는 우측 또는 하단에 구조적으로 배치한다.
7. 장식보다 정보 구조를 우선한다. 표, 차트, 타임라인, 프로세스, 비교표, 실제 이미지가 핵심이다.
8. 마케팅 랜딩페이지처럼 과장하지 않고, 투자자용 제안서처럼 차분하고 명확하게 만든다.
9. 교육자료와 내부 공유자료는 가독성을 최우선으로 한다. 글자가 작거나 빈 공간이 큰 장표는 실패한 장표로 본다.
10. 한 슬라이드의 실제 정보 점유 면적은 최소 65% 이상을 목표로 한다. 의도 없는 큰 여백, 작은 카드, 멀리 떨어진 요소 배치는 피한다.

## 폰트와 타이포그래피

### 권장 폰트

- 1순위: `Pretendard`
- macOS 기본 대체: `Apple SD Gothic Neo`
- 기타 대체: `Noto Sans KR`, `Malgun Gothic`, `Arial`, `Helvetica Neue`, `Aptos`

폰트는 한 자료 안에서 1-2개 이내로 제한한다. 한국어 중심 자료에서는 Pretendard 계열 하나로 통일하는 것이 가장 좋다.

| 역할 | PPT 권장 크기 | 굵기 | 색상 |
| --- | ---: | --- | --- |
| 커버 로고/브랜드 | 14-20 pt | 700 | White |
| 커버 제목 | 38-52 pt | 700-800 | White |
| 커버 부제 | 18-24 pt | 500-600 | White |
| 섹션 라벨 | 12-16 pt | 700 | Brand Blue |
| 본문 메인 제목 | 36-50 pt | 750-800 | Charcoal 또는 Brand Blue |

| 본문 설명 | 18-24 pt | 400-500 | Charcoal |

제목이 어색하게 줄바꿈되면 글자를 무리하게 줄이지 말고 문장을 짧게 다시 쓴다.

### 가독성 우선 규칙

- 16:9 PPT에서 본문 설명은 원칙적으로 18pt 미만으로 내려가지 않는다.
- 교육자료의 핵심 문장과 카드 본문은 20pt 이상을 우선 사용한다.
- 청중이 스크린샷만 봐도 읽을 수 있어야 한다. 작은 글자로 많은 내용을 우겨 넣지 않는다.
- 한 장에 들어가지 않는 내용은 글자를 줄이지 말고 슬라이드를 나눈다.
- PPT 렌더링 후 50% 축소 화면에서도 제목, 핵심 숫자, 주요 문장이 읽혀야 한다.
- PowerPoint 맞춤법 빨간 밑줄이 과도하게 보이는 영문/신조어는 가능한 한 한글 설명을 병기하거나 용어를 줄인다.

## 공통 레이아웃

### 본문 슬라이드 기본 크롬

- 배경: 흰색
- 좌상단 세로 바:
  - 위치: 화면 가장 왼쪽, 상단부터 시작
  - 너비: 슬라이드 폭의 약 1.5-2.0%
  - 높이: 슬라이드 높이의 약 14-18%
  - 색상: Brand Blue
- 섹션 라벨:
  - 위치: 좌측 여백 안, 세로 바 오른쪽
  - 색상: Brand Blue
  - 예: `Intro`, `History`, `브랜드 사업`, `D2C 브랜드 성장 사례`, `비즈니스 시스템`
- 우상단 메타:
  - 작고 회색으로 문서명/페이지 번호 표기
  - 시각적으로 튀지 않게 처리

### 여백과 그리드

- 좌우 여백은 정돈되게 두되, 실제 콘텐츠가 작아질 정도로 넓히지 않는다.
- 기본 외곽 여백은 50-70px 수준을 우선한다.
- 제목 영역은 보통 좌측 32-42%를 사용한다.
- 표, 차트, 이미지, 프로세스는 우측 58-68%를 사용하되 충분히 크게 배치한다.
- 표/차트가 중요한 슬라이드는 제목을 상단 좌측에 두고, 본문 영역 전체를 데이터에 할당한다.
- 요소는 보이지 않는 그리드에 맞춰 정렬한다. 흩어진 배치는 금지한다.
- 카드형 구성은 남발하지 않는다. 카드가 필요할 때는 2-3개 대형 카드 또는 화면을 꽉 쓰는 표/프로세스 형태를 우선한다.
- 4개 이상 작은 카드를 2x2로 띄엄띄엄 배치하는 구성은 피한다. 꼭 필요하면 번호형 프로세스 바, 큰 표, 단계형 레이아웃으로 바꾼다.
- 텍스트 박스와 도형 사이의 간격은 24-40px 범위에서 통일한다. 80px 이상 큰 빈 공간은 의도 없는 여백으로 보고 재배치한다.

## 교육자료 / 내부 공유자료 전용 규칙

- 청중은 내용을 처음 듣는 사람이라고 가정한다.
- 제목은 개념명이 아니라 결론형 문장으로 쓴다.
- 한 장에는 하나의 학습 포인트만 담는다.
- 긴 설명보다 `개념 -> 예시 -> 바로 할 일` 구조를 우선한다.
- 중고등학생도 이해할 수 있는 비유와 업무 예시를 넣되, 화면에는 짧게 남긴다.
- 슬라이드당 본문 bullet은 3개 이하가 좋다.
- 실습 슬라이드는 프롬프트 예시를 크게 보여준다. 예시 프롬프트는 18pt 이상으로 보여야 한다.
- 체크리스트는 작은 표보다 큰 행 단위 리스트로 만든다.
- 흐름 설명은 작은 카드 4개보다 큰 단계 막대 또는 좌우 비교 레이아웃을 우선한다.
- 장표를 만들고 난 뒤 반드시 전체 렌더링 이미지를 확인해서 “발표장에서 읽을 수 있는가”를 기준으로 재작업한다.

## 대표 슬라이드 패턴

### 1. 커버

- 풀 Brand Blue 배경
- 좌상단에 `Childy` 로고 또는 텍스트
- 좌측 중상단에 큰 흰색 제목
- 제목 아래 작은 영문/부제
- 좌하단에 저작권 또는 회사명
- 우하단에는 항상 `운영본부 DX팀 박명수`를 작고 흰색으로 표기한다.
- 별도 이미지나 장식은 넣지 않는다.

### 2. Disclaimer / 안내문

- 흰 배경 + 좌상단 파란 세로 바
- 좌측 상단에 섹션 라벨
- 제목은 짧고 굵게
- 본문은 우측 넓은 영역에 단락형으로 배치
- 박스 장식 없이 문장 정렬과 줄간격으로 정돈한다.

### 3. INDEX / 목차

- 흰 배경 + 좌상단 파란 세로 바
- `INDEX`를 Brand Blue로 표기
- 2-3열 목차 구성
- 항목명과 페이지 번호를 작고 촘촘하게 배치하되 여백은 유지한다.

### 4. 회사 개요

- 좌측: 회사명, 대표자, 설립일, 주소, 사업영역 등 key-value 정보
- 우측: 실제 사무실/현장/제품 관련 사진
- 사진은 큰 직사각형으로 깨끗하게 자른다.

### 5. 연혁 / 타임라인

- 중앙 가로축 기준으로 연도별 마일스톤 배치
- 연도는 작게, 핵심 사건은 짧은 bullet로 정리
- 중요한 시점만 Brand Blue 점/라벨로 강조

### 6. 사업 구조 / 프로세스

- 좌측에 큰 결론 제목
- 우측에 박스, 화살표, 단계 구조
- Pale Blue 패널과 Brand Blue 라인을 사용
- 최종 목표나 결과 블록은 Deep Blue/Brand Blue로 강조

### 7. 데이터 / 성장 사례

- 좌측: 사례명, 핵심 메시지, 짧은 설명
- 우측: 차트, 표, 근거 이미지
- 핵심 성장률/매출/비율은 파란 테두리 콜아웃 또는 큰 숫자로 강조
- 표는 진한 헤더 + 연한 파란 본문 셀을 기본으로 한다.

### 8. 포트폴리오 / 브랜드

- 실제 브랜드 이미지, 로고, 제품/매장 사진을 가로 스트립이나 카드형 블록으로 배열
- 캡션은 짧고 균일하게
- 이미지는 장식이 아니라 증거로 사용한다.

### 9. 조직 / 시스템

- 다단 컬럼 구조, 역할별 박스, 흐름도 사용
- 헤더는 Dark Grey 또는 Brand Blue
- 내부 항목은 Pale Blue pill 또는 흰색 셀로 정리
- DX/시스템 관련 내용은 업무 흐름, 데이터 흐름, 자동화 포인트가 한눈에 보이게 만든다.

## 표 스타일

- 헤더: Dark Grey 또는 Brand Blue 배경 + White 텍스트
- 본문: White와 Pale Blue를 섞어 가독성 확보
- 강조 셀: Brand Blue 배경 + White 텍스트
- 라인: White 또는 Line Grey, 얇게
- 숫자는 가능한 한 정렬 기준을 맞춘다.
- 표가 많을 경우 페이지를 나누고, 한 페이지에 모든 것을 밀어 넣지 않는다.

## 차트 스타일

- 기본 색상은 Brand Blue, Light Blue, Pale Blue, Grey 조합
- 막대/선/버블/단계형 차트를 우선 사용
- 3D 차트, 과한 그림자, 두꺼운 격자선은 금지
- 범례보다 직접 라벨링을 우선한다.
- 핵심 숫자는 별도 콜아웃으로 크게 표시한다.

## 이미지 사용 규칙

- 실제 제품, 브랜드, 매장, 화면, 업무 산출물, 현장 사진을 우선 사용한다.
- 이미지는 직사각형으로 깨끗하게 크롭한다.
- 흐림 처리, 어두운 오버레이, 분위기용 스톡 이미지는 피한다.
- 웹페이지 프리젠테이션에서도 배경 장식 이미지보다 근거 이미지/스크린샷으로 사용한다.

## 문체와 메시지

- 톤: 투자자용, 파트너 제안용, 임원 보고용
- 문장은 짧고 결론 중심으로 쓴다.
- 제목은 설명문보다 결론형으로 쓴다.
- 본문은 `주장 -> 근거 -> 기대 효과` 순서가 좋다.
- DX팀 관점 자료는 기술 자체보다 비즈니스 개선 효과를 먼저 말한다.

좋은 제목 예시:

- `브랜드 인큐베이팅 비즈니스`
- `라이선스 브랜드 비즈니스`
- `비즈니스 시스템 고도화`
- `단순 관리를 넘어, 비즈니스 전반의 효율화 실행`
- `데이터 기반 운영 체계 구축`

피해야 할 표현:

- 너무 캐주얼한 말투
- 근거 없는 과장
- 장식적인 카피
- 이모지
- 불필요한 영어 남용

## PPT 제작 시 적용 규칙

- PowerPoint 크기는 16:9 와이드로 설정한다.
- 가능하면 Pretendard를 사용하고, 없으면 Apple SD Gothic Neo로 대체한다.
- 도형은 직사각형, 얇은 라인, 원형 배경, pill 형태 정도로 제한한다.
- 슬라이드마다 제목/본문/근거 자료의 정렬 기준을 통일한다.
- 페이지 번호와 문서명은 우상단에 작게 둔다.
- 완성 후 모든 페이지를 이미지로 렌더링해 글자 겹침, 표 깨짐, 잘림을 확인한다.
- 렌더링된 전체 슬라이드 컨택트시트를 눈으로 확인한다.
- 글자가 작아 보이거나 레이아웃이 비어 보이면 완성으로 보지 않고 재배치한다.
- 정보가 적은 슬라이드는 더 큰 타이포그래피, 좌우 비교, 큰 프로세스, 핵심 문장 강조 등으로 화면을 적극 활용한다.
- 정보가 많은 슬라이드는 작은 글자로 압축하지 말고 슬라이드를 분리한다.

## PDF 제작 시 적용 규칙

- PPT와 같은 16:9 페이지 비율로 만든다.
- 인쇄용 문서처럼 세로 A4로 바꾸지 않는다. 사용자가 명시하면 예외로 한다.
- 폰트 깨짐 방지를 위해 가능한 PDF에 폰트를 임베딩한다.
- 표/차트는 축소해도 읽히도록 최소 글자 크기를 유지한다.
- 완성 후 페이지별 PNG 렌더링으로 레이아웃을 검수한다.

## 프리젠테이션 웹페이지 제작 시 적용 규칙

- 첫 화면부터 발표자료 자체가 보여야 한다. 랜딩페이지처럼 만들지 않는다.
- 슬라이드 단위 섹션을 16:9 비율로 구성한다.
- 데스크톱에서는 한 화면에 한 슬라이드가 안정적으로 보이게 한다.
- 모바일에서는 슬라이드 비율을 유지하되, 글자가 너무 작아지면 세로 스택으로 재배치한다.
- 본문 슬라이드에는 좌상단 파란 세로 바와 섹션 라벨을 유지한다.
- 표/차트/이미지는 실제 발표자료처럼 정돈된 정보 블록으로 둔다.
- 웹 인터랙션은 발표 흐름을 돕는 정도로만 사용한다. 과한 애니메이션은 피한다.
- PDF 출력/프린트 시 배경색과 레이아웃이 유지되도록 CSS를 구성한다.

## 기본 작업 흐름

1. 요청 목적을 먼저 파악한다: 투자, 제휴, 내부 보고, DX 과제 제안, 사업 계획, 교육 자료 중 무엇인지 확인한다.
2. 청중을 정한다: 투자자, 경영진, 브랜드팀, 개발팀, 외부 파트너 등.
3. 전체 구조를 먼저 만든다: 커버 -> 문제/기회 -> 근거 -> 전략 -> 실행 계획 -> 기대 효과.
4. 슬라이드별 핵심 메시지를 1문장으로 정한다.
5. 각 메시지를 뒷받침할 표, 차트, 이미지, 프로세스 중 하나를 배치한다.
6. Childy 양식의 색/폰트/여백/세로 바/우상단 메타를 적용한다.
7. 완성 후 렌더링해서 시각 검수한다.

## 웹프리젠테이션 레퍼런스 (핫딜 단가 보고서 기준)

아래는 실제 잘 나온 산출물 기준으로 정리한 웹프리젠테이션 구체 스펙이다.
이후 웹PPT를 만들 때 이 섹션을 우선 참조한다.

### 커버 페이지 구성

- 풀 Brand Blue 배경, 좌측 정렬
- 상단: 작은 서브 타이틀 (예: "핫딜 커뮤니티") — 16~18px, 반투명 흰색
- 중앙: 메인 타이틀 — 52~56px, font-weight 800, 흰색
- 메인 타이틀 아래: 설명 1줄 — 20~22px, opacity 0.8, 흰색
- 하단: 좌측에 날짜·문서 성격 (예: "2026.07.03 · Internal Review"), 우측에 "운영본부 DX팀 박명수" — 14px

### 본문 슬라이드 기본 구조

- 배경: 흰색
- 좌상단 파란 세로 바: 폭 24px, 높이 130px, Brand Blue
- 섹션 라벨: 좌상단, 16px, 700, Brand Blue (예: "Executive Summary", "Analysis Basis")
- 페이지 번호: 우상단, 15px, #999
- **페이지 번호 왼쪽에 문서명을 작게 표기** (예: "핫딜 단가 검토 보고서 · 02") — 14px, #bbb
- 패딩: 좌우 80px, 상하 콘텐츠는 수직 중앙 정렬

### 타이포그래피 (웹PPT 기준)

| 역할 | 크기 | 굵기 | 비고 |
|------|------|------|------|
| 커버 메인 타이틀 | 52~56px | 800 | 흰색 |
| 본문 슬라이드 제목 (h2) | 42~46px | 800 | Charcoal |
| 본문 서브 헤딩 | 24~28px | 700 | Charcoal 또는 Brand Blue |
| 본문 설명 (p) | 22~24px | 400~500 | #3C4646 |

### 레이아웃 패턴

1. **결론 선행형**: 제목 바로 아래에 1~2문장 결론(서브 헤딩 크기)을 넣고, 그 아래 근거(테이블/카드)를 배치한다.
2. **3열 카드형**: 핵심 판단 3가지를 가로 카드로 배치. 카드는 전체 너비를 꽉 채운다.
3. **테이블 풀와이드**: 테이블은 슬라이드 가로 전체를 쓴다. 좌우 패딩(80px) 안에서 width:100%.
4. **2열 분할 (텍스트 + 지표)**: 좌측에 본문 설명, 우측에 핵심 숫자 카드 또는 지표 블록.
5. **단계형 플로우**: 가로 5단계 이내, 화살표 연결, 중앙 정렬.

### 카드 스타일

- 배경: #E6F0FA (Pale Blue) 또는 흰색+보더
- border-radius: 14px
- 패딩: 28~32px
- 카드 내부: 상단에 라벨(14~15px, Brand Blue, bold), 하단에 값(20~22px, bold, Charcoal)
- 카드 사이 간격: 20px

### 뱃지 활용

- 용도: 판단 결과(집행 가능 / 조건부 검토 / 비추천), 필수/선택 구분, 등급 표시
- 크기: font-size 13~14px, padding 6px 16px, border-radius 6px
- 색상 분리:
  - 긍정/집행 가능: Brand Blue 배경 + 흰색 텍스트
  - 주의/조건부: #F59E0B (amber) 배경 + 흰색 텍스트
  - 부정/비추천: #DC2626 (red) 배경 + 흰색 텍스트
  - 중립/선택: #E5E5E5 배경 + #555 텍스트

### 테이블 스타일 (웹PPT)

- 헤더: Brand Blue 배경, 흰색 텍스트, 18px, padding 18px 24px
- 본문 행: 홀수 흰색, 짝수 #F6FBFF (Ice Blue 계열)
- 셀 padding: 18px 24px
- 강조 셀(금액, 핵심 숫자): Brand Blue 색상, bold, 22~26px
- 판단 열: 뱃지 + 짧은 설명 조합
- 하단 각주: 14px, #888, margin-top 16px

### 콜아웃 / 판단 블록

- 배경: #FFF7ED (연한 amber 계열) 또는 Pale Blue
- border-left: 4px solid Brand Blue 또는 amber
- 내부: 라벨(bold, 14px) + 본문(18~20px)
- 용도: 최종 판단, 핵심 의견, 주의사항 강조

### 슬라이드 흐름 구성 (내부 보고서 기준)

1. **커버** — 주제, 문서 성격, 작성자
2. **Executive Summary** — 핵심 결론 1장 (결론 선행)
3. **분석 기반** — 데이터 출처, 분석 조건, 핵심 지표 카드
4. **등급별 분석** — 테이블 중심, 등급별 CPM/판단
5. **손익분기** — 필요 주문수 테이블
6. **숏리스트** — 추천 채널 테이블 + 뱃지
7. **채널 상세** — 채널별 2열 카드 (추천 이유 + 판단)
8. **협상 범위** — 적정가 테이블
9. **제외 기준** — 카드형 요약
10. **대행사 요청사항** — 단계형 + 협상 콜아웃
11. **최종 추천** — 3열 카드 요약 + 최종 의견 콜아웃

### 절대 하지 말 것

- 콘텐츠를 좌상단에만 몰아넣고 우측/하단을 비워두는 것
- 폰트를 16px 이하로 작게 쓰는 것 (각주/출처 제외)
- 슬라이드 안에서 콘텐츠 점유 면적이 50% 이하인 것
- Q&A / 마감 슬라이드를 넣는 것
- aspect-ratio로 슬라이드 크기를 잡는 것 (고정 1280x720px 사용)
