# 이미지 캡처 & 디버깅 지침

이 프로젝트에서 "화면을 이미지로 내려받기" 기능을 붙이거나, 화면 렌더링 관련 버그를 잡을 때 반드시 따를 규칙. (2026-09 간트차트 내려받기 작업에서 얻은 교훈)

## 1. 화면 → 이미지 캡처는 html-to-image를 기본으로 쓴다

- **html2canvas 금지(기본).** DOM을 재해석해 다시 그리면서 텍스트 baseline·테이블 열폭을 추측해 어긋난다. 특히 한글, 테이블, 간트처럼 정밀한 레이아웃에서 텍스트가 세로로 쏠리거나 특정 열이 통째로 누락된다. 상쇄값(top/line-height)으로 쫓아가지 말 것 — 근본 해결이 안 된다.
- **html-to-image(SVG foreignObject)를 사용.** 브라우저 네이티브 렌더러가 화면 그대로 그리므로 정렬이 화면과 100% 일치한다.
  - CDN: `https://cdn.jsdelivr.net/npm/html-to-image@1.11.11/dist/html-to-image.js`

## 2. html-to-image 안전 캡처 패턴 (downloadGantt 참고)

1. **오프스크린 복제본을 캡처한다.** 원본 DOM은 절대 건드리지 않는다.
   - `target.cloneNode(true)` → `position:fixed;left:-99999px` 홀더에 append → 캡처 후 홀더 제거
2. 복제본에서 **sticky/fixed → static** 으로 변환 (원위치/고정위치 이중 렌더 잔상 방지)
3. **편집용 UI 제거**: `[data-html2canvas-ignore]` 요소, 행별 삭제버튼/hover 버튼 등을 복제본에서 `remove()`
4. **줄바꿈 위험 텍스트(제목 등)에 `white-space:nowrap`** — 캡처 폭에서 줄바꿈되면 아랫줄 글자가 위 요소로 넘쳐 "잔상"처럼 보인다
5. `<input>` 값은 `cloneNode`가 반영 안 할 수 있으니 `setAttribute('value', ...)`로 복사
6. 폰트 임베드 위해 `await document.fonts.ready` 후 캡처
7. **`width`/`windowWidth` 같은 폭 강제 옵션을 함부로 쓰지 말 것** — 테이블 열 계산이 틀어져 특정 열이 누락된다. `pixelRatio`(해상도)만 지정하고 크기는 복제본 실제 크기(`scrollWidth/scrollHeight`)를 따르게 한다
8. 파일명은 의미 있게 + 날짜 스탬프 (예: `DX팀_마일스톤_간트차트_YYYYMMDD.png`)

## 3. 디버깅 원칙 (렌더링/캡처 이슈 공통)

- **확실히 검증하기 전에 "해결됐다"고 말하지 않는다.** 추측 기반 패치를 성공으로 표현하지 말 것.
- **같은 증상이 2번 이상 반복되면 즉시 멈추고 재현 환경부터 실제와 일치시킨다.** 로컬 간이 재현(적은 데이터/짧은 텍스트/다른 화면폭)은 실제 버그를 숨긴다. 필요하면 실제 배포 사이트 + 실제 계정 + 실제 데이터로 재현한다.
- **원인은 변수를 하나씩 격리해서 확정한다.** 옵션 A/B, 라이브러리 유무 등을 각각 캡처해 비교. 정렬은 눈대중 대신 픽셀/수치로 측정한다.
- **근본 원인을 못 잡고 상쇄값만 쌓이면, 접근(라이브러리/방식) 자체를 바꾼다.**

## 4. 재사용

새 화면(월간업무공유, R&R, 요청관리 등)에 이미지 내보내기를 붙일 때는 `script.js`의 `downloadGantt`의 clone + html-to-image 패턴을 그대로 재사용한다. 공용 함수로 추출하는 것을 우선 고려한다.
