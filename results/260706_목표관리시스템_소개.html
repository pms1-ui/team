시스템 도입 배경

기존 목표 관리의 한계를 데이터 기반 시스템으로 해결합니다.

기존 문제해결 방향
목표가 구두로만 공유, 가시성 없음웹 기반 실시간 대시보드로 전사 투명 공개
성과 평가 시 정성적 감에 의존3축 정량 평가 + AI 자동 분석으로 객관성 확보
피드백이 연간 1회 또는 사실상 전무주간 체크인 + 중간 리뷰 + 분기 회고 루프 상시화
업무 범위(R&R)가 불명확직무기술서 + M/D 기반 업무량 산정 체계 구축
목표 수정/변경 이력 추적 불가승인 워크플로우 + 변경 전후 비교 + 이력 아카이빙

OKR 수립 원칙

선택과 집중, 업무(Task)가 아닌 결과(Outcome) 중심의 목표 정의

Objective

정성적이고 고무적인 짧은 한 문장
분기당 3~4개

올바른 예시

"우리 카테고리에서 가장 빠른 온보딩 경험 만들기"

Key Result

비즈니스 임팩트를 측정하는 정량 지표
Objective당 3개 내외, 단독 오너십 필수

작성 공식

[세그먼트]의 [비즈니스 결과]를
[baseline]에서 [target]으로 개선

달성률에 따른 목표 수준 판단

100% 달성
목표가 너무 쉽게 설정됨
→ 다음 분기 상향 조정 필요
70~80% 달성
적절한 도전 수준
→ 가장 이상적인 목표 설정
50% 미만
목표가 지나치게 도전적이었거나
→ 실행력 부족 여부 검토

AI 피드백 — 객관성 담보

단순 달성률이 아닌 업무량·성취도·비즈니스 임팩트를 종합 반영합니다.

평가 축비중평가 내용
직무적합성30%R&R 대비 OKR 정합성, 본연의 역할 수행
역량40%OKR 설계 정량성, KR 달성 수준, 기술 난이도 대비 실행력, 업무 분량 적정성
근면성실도30%실제 진척률, 체크인 업데이트 빈도, 목표 대비 착수 비율

M/D 업무량 검증

  • 분기 가용 시간: 60 M/D 기준
  • 직군별 벤치마크 적용 (인스타 주2회=12 M/D 등)
  • 목표 합산이 가용 시간에 크게 못 미치면 감점
  • 반복 운영만으로 채우면 도전성 부족 감점

종합 점수 산출

종합 = (직무적합성 × 0.3) + (역량 × 0.4) + (근면성실도 × 0.3)

10점 만점, 0.1점 단위

8.0+ 우수 6.5~7.9 양호 ~6.4 개선필요
Feedback Release
11

피드백 공개 프로세스

사전 설정된 시점에 피드백이 공개되며, 열람 범위는 소속 기준으로 제한됩니다.

공개 방식

  • 팀장/본부장 피드백 → 사전 설정된 시점에 구성원에게 공개
  • AI 피드백 리포트 → 별도 전달

열람 가능 정보

  • Objective별 피드백 내용
  • 작성자명 + 작성일
  • Grade (관리자만 열람)

열람 권한 제한

구성원 열람 범위
• 본인에게 작성된 피드백만 열람 가능
• 타 본부, 타 팀 구성원의 피드백 정보는 열람 불가
• 대표/본부장/팀장은 소속 범위 내 조회 가능
