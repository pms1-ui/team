# AI 피드백 리포트 생성 가이드

## 개요
이 폴더에는 AI가 생성한 구성원 피드백 리포트(HTML)가 저장됩니다.
사용자가 "AI 피드백" 또는 "구성원별 종합 리뷰"를 요청하면 이 가이드에 따라 동일한 UI로 생성합니다.

## 파일 네이밍 규칙
```
{팀명}_{분기}_{연도}_review.html
```
예시: `dx_q2_2026_review.html`, `cx_q3_2026_review.html`

## 데이터 소스
1. **직무기술/R&R** — Baserow `rnr` 테이블 (table_id: 1945)
2. **OKR + Key Results** — Baserow `goals` 테이블 (1943) + `key_results` 테이블 (1944)
3. **구성원 정보** — Baserow `members` 테이블 (1942)

## 평가 기준 (3개 축)

| 기준 | 비중 | 평가 내용 |
|---|:---:|---|
| 직무적합성 | 30% | R&R에 명시된 직무 범위 대비 OKR이 적절히 설정되었는지, 본연의 역할을 수행하고 있는지 |
| 역량 | 40% | OKR 설계의 정량성/구체성, KR 달성 수준, 기술적 난이도 대비 실행력, 업무 분량의 적정성 |
| 근면성실도 | 30% | 진척률 업데이트 빈도, 목표 대비 실제 착수 비율, OKR 시스템 참여도 |

## 종합 점수 산출
```
종합 = (직무적합성 × 0.3) + (역량 × 0.4) + (근면성실도 × 0.3)
```
- 10점 만점, 0.1점 단위
- 소수점 첫째 자리까지 표기

## HTML 구조 및 스타일

### 전체 레이아웃
- `max-width: 900px`, 중앙 정렬
- 배경: `#f8fafc`
- 폰트: Pretendard (시스템 폰트 폴백)

### 구성원 카드 (`.member-card`)
```
┌─────────────────────────────────────────────┐
│ [이름]                           [종합 점수]  │
│ [직책 · 직무]                    / 10.0      │
├─────────────────────────────────────────────┤
│  직무적합성: X.X  │  역량: X.X  │  근면성실도: X.X │
├─────────────────────────────────────────────┤
│ [종합 평가]                                   │
│ - 서술형 평가문 (구체적 수치 포함)             │
│ [강점 태그] [개선 태그]                        │
└─────────────────────────────────────────────┘
```

### 색상 체계
- 점수 뱃지 배경: `linear-gradient(135deg, #eff6ff, #dbeafe)`
- 점수 텍스트: `#1d4ed8`
- 강점 태그: `background: #dcfce7; color: #166534;`
- 개선 태그: `background: #fef3c7; color: #92400e;`

### 하단 요약 테이블
- 모든 구성원의 점수를 한눈에 비교
- 종합 점수 컬럼은 bold + primary color 강조

## 평가 작성 가이드라인

1. **구체적 수치 인용**: "진척률 70%", "KR 12개 중 3개 달성" 등 데이터 기반 서술
2. **비교 관점**: 동일 직군 내 상대적 수행도 언급
3. **R&R 대비 실행**: 직무기술서에 명시된 핵심 업무를 실제로 수행했는지 판단
4. **업무 분량 적정성**: OKR/KR 수가 직무 범위 대비 과다/과소인지 언급
5. **강점/개선 태그**: 각 구성원당 강점 2~3개, 개선점 1~2개 태그로 요약
6. **감정 배제**: 객관적 사실과 수치에 근거한 평가만 작성

## 생성 절차

1. 대상 팀/기간 확인
2. Baserow에서 해당 팀 members, rnr, goals, key_results 데이터 조회
3. 구성원별 직무적합성 / 역량 / 근면성실도 채점
4. 종합 평가문 작성
5. HTML 파일 생성 → `feedback/` 폴더에 저장
6. git commit & push
